# GeoFS-V4.0_Design-System

![Version](https://img.shields.io/badge/Version-v1.0.1-3b82f6?style=flat-square)

Provides shared GeoFS-style controls and styling for the ecosystem.

## Features

- Applies common styles to supported panels, controls, and HUD elements.
- The library is used by the other standalone scripts as a shared dependency.

## Installation

1. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/).
2. Install or update the script from [Greasy Fork](https://greasyfork.org/en/scripts/604887).
3. Open or reload GeoFS V4.0. The script starts automatically.

The script activates only when GeoFS reports a supported version 4 release (including 4.x releases). It waits for the version to become available and remains inactive on other versions. The Design System loads the Core Library as a dependency; the userscript manager handles that dependency.

The **GeoFS-V4.0_Ecosystem** panel lists detected add-ons and reported initialization failures. Select × to dismiss it; it closes automatically after startup if no failure is reported.
