# GeoFS-V4.0_Design-System

Experimental shared styles and accessible UI helpers for the GeoFS V4.0 ecosystem. Requires the V4 Core Library, loaded automatically through the userscript manager. It activates only after GeoFS 4 and an aircraft are ready.

The `window.GeoFSV4Design` API offers `button(label, action)` and `panel(title)`; classes are scoped with the `g4-` prefix. Version 0.1.0 is an initial foundation, subject to live beta testing.

Install with a userscript manager and reload GeoFS 4.0 Beta. The script does not affect flight controls.
